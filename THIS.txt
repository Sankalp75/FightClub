10. api/bulk-email.js — VERCEL SERVERLESS (71 lines)
----------------------------------------------------
- Imports nodemailer 6.9.13.
- Env vars needed in Vercel Dashboard: SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY (bypasses RLS), GMAIL_USER, GMAIL_APP_PASSWORD (16-char app password, spaces stripped), BULK_SECRET.
- Handler: CORS * allow POST OPTIONS + x-bulk-secret, 405 if not POST, 401 if secret mismatch, 400 if missing subject, 500 if missing env.
- Fetches contacts: GET SUPABASE_URL/rest/v1/joins?select=contact with service_role headers → rows → emails = dedup lowercased filtered by RFC regex /^[a-z0-9._%+-]+@[a-z0-9.-]+\.[a-z]{2,}$/. 404 if empty.
- Transporter nodemailer.createTransport service gmail auth user/pass.
- Chunk emails 50 per batch (BCC limit), loops sendMail from GMAIL_USER to GMAIL_USER bcc batch subject html/text, sent counter, 502 on fail.
- Returns 200 {ok:true,sent,total,from}.

16. DEPLOYMENT / HOW TO RUN
--------------------------
- No build, no npm worship for frontend: git clone + open index.html or python3 -m http.server 8000. Use laptop 1920×1080, mouse.
- GitHub Pages: Settings → Pages Source main /(root) → https://sankalp75.github.io/FightClub/
- Vercel: connects repo for /api/bulk-email.js, env vars set, package.json module required. Live at hustle24.vercel.app/api/bulk-email used by admin.html.
- Supabase: project afdrdgtc..., table joins, anon insert policy. Data under 400KB images JPEG q80 cover blur10.
- Git push flow: git add . commit "wake up" pull --rebase push origin main.

17. ASSETS & CONSTRAINTS
-----------------------
- Images all 1920×1080 cover, blurred 10px, transforms scale. Don't use 4K PNG.

- No responsiveness: mobile intentionally blocked.
- Security: contact field blocks capitals (pattern + JS), Supabase anon key is low-privilege insert-only, bulk needs BULK_SECRET + service_role key server-side only. Admin secret stored localStorage.
